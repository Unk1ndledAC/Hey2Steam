      How it works

      Three steps, one click

      1

      Fetch

      Pull the HeyBox wishlist for the given user ID.

      2

      Compare

      Diff against the current Steam wishlist to find missing games.

      3

      Sync

      Add each missing game to Steam using your access token.

      Where do I get these credentials?

      Steam

      1. SteamID64 — from steamid.io or your profile URL.
      2. Access token — log into Steam, open the pointssummary/ajaxgetasyncconfig page, copy webapi_token.
      3. API key (optional) — steamcommunity.com/dev/apikey.

      HeyBox (小黑盒)

      1. User ID — the numeric ID in your HeyBox profile or API requests.
      2. The wishlist must be public; otherwise a pkey login credential is needed (backend only).
      3. Signature is computed automatically (web or chat).
